# Cursor Usage PRD

## 目标

为 Windows 用户提供一个轻量桌面面板，快速查看 Cursor 当前月度账期的 Cursor Models 用量和 API 用量。

## 范围

- 显示 Cursor Models、Other Models 两类已使用百分比、计划类型和月度账期重置时间；百分比按 Cursor Dashboard 规则向上取整。
- 支持 Cursor Dashboard、指定 JSON、手动和演示数据源。
- 默认每 30 秒后台刷新；托盘右键菜单仅提供刷新和退出操作。
- 首次启动显示在右下角；用户拖动后，窗口位置在下次启动时恢复。
- 悬浮窗固定宽度为 240 像素；每次显示时在 Windows 原生置顶层重新确认位置，避免被普通窗口覆盖。
- 自动读取 Cursor IDE 的本地登录状态，环境变量仅用于手动覆盖。
- 会话凭据仅在内存中使用，不写入应用配置、不显示或打印。
- 本次运行已有成功数据时，后续获取失败仍展示最近一次成功数据，并附带本次失败原因；首次获取失败时显示空数据状态。

## 验收

- Cursor IDE 已登录时，无需手工复制 Cookie 即可获取真实用量。
- 无 Cookie、网络错误或响应变化时显示明确状态，不泄露凭据。
- 成功获取后再次刷新失败时，用量数值保持为最近一次成功结果，状态区域显示失败原因。
- JSON 与手动数据源可独立工作。
- 双击启动脚本后，应用不依赖启动终端；关闭窗口时保留托盘入口。
- 拖动窗口后退出并重新启动，窗口显示在上次保存的位置。
